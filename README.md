# Financial News Sentiment Prediction using Deep Learning & BERT

An NLP project that classifies English financial tweets and headlines into **Bearish**, **Bullish**, or **Neutral** sentiment.

The project compares Simple RNN, LSTM, and fine-tuned BERT models and provides a Streamlit dashboard for interactive predictions.

## Project Objectives

- Explore and validate a financial sentiment dataset.
- Build Simple RNN and LSTM classifiers from scratch.
- Fine-tune pretrained BERT on the same training examples.
- Compare models using accuracy, macro F1, and class-wise metrics.
- Export trained models for reusable inference.
- Build a Streamlit application that displays sentiment predictions and probabilities.

## Technology Stack

- **Language:** Python
- **Data analysis:** pandas, NumPy
- **Visualization:** Matplotlib, Seaborn
- **Deep learning:** PyTorch

## Dataset

**Source:** [Twitter Financial News Sentiment](https://huggingface.co/datasets/zeroshot/twitter-financial-news-sentiment)

| Label | Sentiment |
|------:|-----------|
| 0 | Bearish |
| 1 | Bullish |
| 2 | Neutral |

The recorded dataset contains:

- **9,543** official training examples.
- **2,388** official validation examples.

The data audit excludes invalid training text, conflicting labels, duplicate training examples, and training examples overlapping with validation.

After filtering, **9,396 training examples** remain eligible for the internal fitting/development split. The official validation split is preserved.

## Installation

Python 3.11 or 3.12 is recommended.

Open a terminal in the project folder and create a virtual environment:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Install the project dependencies and notebook tools:

```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt notebook \
  "transformers==4.57.6" \
  "streamlit>=1.50,<2" \
  "reportlab>=4,<5" \
  "ipywidgets>=8,<9"
```

An internet connection is required for the initial dataset and pretrained-model downloads.

## Run the Notebook

Start Jupyter:

```bash
python -m notebook financial_news_sentiment.ipynb
```

Select the kernel associated with your virtual environment and run the cells in order.

The notebook follows 20 steps covering data preparation, model training, evaluation, inference, and application export.

### Execution Modes

Configure the mode in the notebook:

```python
RUN_MODE = "full"
```

- **full:** Uses all eligible training examples for the planned experiments.
- **smoke:** Uses small subsets and fewer epochs to check pipeline execution.

Smoke-mode scores should not be presented as final model performance.

Training uses CUDA when available, otherwise Apple MPS when available, otherwise CPU. BERT training can take substantially longer on CPU.

## Data Preparation and Evaluation

The pipeline:

1. Inspects the dataset schema and label values.
2. Audits missing text, duplicates, conflicting labels, and split overlap.
3. Creates a stratified development subset from eligible training data.
4. Fits the vocabulary and calculates class weights using fitting data only.
5. Preserves tickers, numbers, percentages, and negation during preprocessing.
6. Uses development macro F1 for checkpoint and model selection.
7. Evaluates frozen candidates on the official validation split.

The official validation split is reserved for final comparison. It is not described as an independent test set.

## Models

### Simple RNN

A randomly initialized embedding layer followed by a recurrent layer, masked pooling, dropout, and a three-class classifier.

### LSTM

Uses the same input preparation and classifier structure with an LSTM recurrent layer.

### BERT

Fine-tunes `google-bert/bert-base-uncased` with a three-class classification head.

Training includes early stopping, checkpoint saving, gradient clipping, and class-weighted loss. BERT also uses learning-rate scheduling and gradient accumulation.

## Recorded Official-Validation Results

The saved full-run comparison reports:

| Model | Accuracy | Macro F1 |
|-------|---------:|---------:|
| Simple RNN | 76.26% | 0.6731 |
| LSTM | 77.05% | 0.6821 |
| BERT | **86.35%** | **0.8296** |

**BERT was selected for deployment using internal development macro F1 before final validation.**

Class-wise precision, recall, F1, confusion matrices, and prediction errors are saved in the run's `reports/` directory.

Results may vary across hardware, dependency versions, and subsequent training runs.

## Run the Streamlit Application

Complete notebook **Step 18** to export the inference files and **Step 19** to export the dashboard data.

From the project folder, run:

```bash
python -m streamlit run app.py
```

The application automatically discovers exported runs inside `financial_sentiment_outputs/`. You can select a run or enter a custom run-folder path in the sidebar.

### Application Features

- Financial text input.
- Bearish, Bullish, or Neutral prediction.
- Class-probability chart and table.
- Validation class-distribution chart.
- Recorded model-comparison table.
- Empty-input handling and long-input truncation warnings.

If no exported model is found, complete the notebook export steps and refresh the application.

## Command-Line Prediction

The notebook also generates `predict.py` inside each exported run.

From that run folder:

```bash
python predict.py "The company reported earnings above expectations."
```

The script returns the predicted sentiment and class probabilities as JSON.

## Reports and Reproducibility

Complete **Step 20** to generate the comparison PDF, environment documentation, and downloadable run archive.

The pipeline records dataset/model revisions, configuration, split membership, and training histories. Each new run receives a separate output folder.

Keep the complete run folder together: inference requires the manifest, exported Python module, and saved model artifacts.

## Limitations

- Prediction accuracy is measured, not guaranteed.
- Model probabilities are not calibrated confidence estimates.
- Evaluation uses financial tweets; performance on longer paragraphs requires separate assessment.
- Text-fingerprint checks do not identify every near duplicate or shared market event.
- Sentiment classification does not establish future stock-price direction.
